# 知识库目录

本仓库**不包含示例知识库**（知识库内容不公开）。请把你自己的知识库命名为
`knowledge.txt` 放在本目录：

```text
data/knowledge/knowledge.txt
```

也可以把文件放到任意位置，然后用环境变量指向它：

```bash
CSA_KNOWLEDGE_DIR=/path/to/your/knowledge
```

## 文本格式

- 章节分隔符：单独一行 `==============================`（前后各留一个空行）
- 章节标题：中文序号 + `、` + 标题，例如 `一、产品简介`、`六、退款规则`
- 正文建议：每条规则"条件 + 结论"写在同一段；数字与单位写法保持一致

最小示例：

```text
==============================
一、产品简介
==============================
这里写产品简介。

==============================
二、套餐说明
==============================
1. 基础版
- 价格：99 元 / 用户 / 月
- 成员人数上限：10 人
```

> `data/knowledge/*` 已在 `.gitignore` 中排除（仅本说明文件除外），
> 避免私有知识库被误提交到公开仓库。
